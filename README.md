# Ascend

AI-personalized self-improvement platform — currently building the first module: **fitness**.

## What is Ascend?

Ascend brings together personalized plans, curated resources, and habit tracking in one place, so you don't have to piece together tools and information from all over the internet. Long-term vision: a connected "life OS" covering multiple life areas, not just fitness.

## Current status

Early-stage, solo-built. Working on the first module (fitness: training plan generator, curated resources, habit tracking, mindset coaching) as a personal-use MVP before opening it up to others.

## About this repo

This is a public showcase repo — project overview, concept docs, and select code. The core codebase lives in a private repository.
